# Project guide

This is My PA, a local-first English/Arabic personal assistant. The only app is the Expo SDK 58 (React Native) app in mobile/, which runs on phones and is published as the website. A shared Node.js/TypeScript API lives in server/ and code used by both in shared/. Do not introduce Python.

- Read README.md and docs/ARCHITECTURE.md before substantial changes.
- mobile/ has its own package lock. Keep screens in mobile/src/features, the shell and UI kit in mobile/src/app, persistence and sync in mobile/src/data, and device adapters in mobile/src/platform.
- Use shared/domain.ts for data types and reuse shared/ logic instead of duplicating it in the app or server.
- Device APIs differ between phones and browsers: put the browser version in a `.web.ts` file next to the native one rather than branching on Platform inside screens. Do not use DOM APIs in native-only files.
- Preserve the mypa_expo_v1 AsyncStorage key, the mypa_pin / mypa_phone_unlock lock keys, and the mypa_session SecureStore key unless implementing a deliberate compatible migration.
- Keep API keys out of source, fixtures, EXPO_PUBLIC variables, logs, and committed files.
- Preserve Arabic, RTL layout, safe areas, the app lock, and offline task/note/habit behavior.
- After substantial changes run npm run check, npm run expo:check, `npx expo install --check` in mobile, npm run export in mobile, and npm run test:expo. Browser tests do not establish native device API compatibility.
- Native projects are generated by Expo (prebuild/EAS) and are not committed. Never commit signing materials.
- See docs/EXPO.md for phone setup and docs/DEPLOYMENT.md for the API and website.
